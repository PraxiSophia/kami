# Owner notes

This folder is reserved for manually authored notes, questions, decisions-in-progress, meeting notes, and explanations requested by the project owner. Automated or semi-automated vault updates must not overwrite files in this folder.

Use a clear date in filenames or frontmatter. Link to the relevant Jira issue and canonical source when useful. A manual note is not an approved project decision unless the authoritative project record says so.
